# Data Studio 目录

- `backend/main.py`：插件注册及运行接口。
- `backend/order_contract.py`：Data Core 订单响应和 Agent 上下文合约。
- `backend/agent_tools.py`：带 Data Core 溯源信息的 Agent 风险工具。
- `backend/*_engine.py`：风险、趋势、简报和跨部门指标引擎。
- `ui/index.js`：实时订单看板、筛选、状态展示和 Agent 上下文交互。
- `tests/`：后端、前端状态、Data Core 合约、Agent 工具和运行接口测试。
