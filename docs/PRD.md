# Data Studio 产品需求（v0.8.0）

## 实时客户订单进度看板

页面以 AI-OS Data Core 的持久化订单为唯一事实来源，首选调用
`GET /zhiyun-data-core/orders`。看板展示订单号、客户、产品、数量、交期、状态、
进度、数据来源及规则计算的交付风险。

用户可按关键词、客户、状态、风险和真实/模拟来源筛选。Data Core 返回空数组时
必须展示真实空状态；加载失败、服务不可用、返回契约错误及字段缺失均须明确显示，
不得以演示数据降级。Data Core 数据库新增或更新订单后，用户刷新页面即可重新查询。

用户可以选中具有 `record_id` 和 `source_type` 的订单作为应用内 Agent 上下文。
缺少上述溯源字段的记录不得提交给 Agent；Agent 风险结果必须携带两项字段。
只有宿主明确提供 `Q.setAgentContext` 时前端才提交上下文；缺少宿主契约时必须
显示错误，不得通过无人接收的自定义事件假装提交成功。

## 验收口径

- Data Core 是订单数据唯一来源；模拟数据仅可由用户显式生成并标注。
- 支持加载、空数据、接口失败、Data Core 不可用和字段缺失状态。
- 后端合约、前端状态、Agent 工具及运行接口均有自动化测试。
